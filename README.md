# VELORA Calculator Website

Luxury dark-and-gold calculator and unit converter.

## Publish with GitHub Pages from your phone
1. Create a public repository named `VeloraCalculator` on GitHub.
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then Save.
6. Wait a minute or two. GitHub Pages will show your website URL on the Pages settings screen.

No build step is required; this is a static HTML site.
